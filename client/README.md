# Administrador de tareas Frontend

Aplicación desarrollada durante el elemento de competencia 2 de Diseño Frontend con Frameworks.

## Tecnologías
- React
- TypeScript
- Vite
- PNPM
- CSS

## Alcance actual
El cliente se conecta a la API de Task Manager para autenticar usuarios y consultar, crear, editar y actualizar tareas. La URL de la API se configura con `VITE_API_URL`.

## Instalación
```bash
pnpm install
pnpm dev
